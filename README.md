# WireGuard Telegram Bot

Telegram-бот для управления WireGuard VPN на роутере MikroTik (RouterOS 7).
Работает через RouterOS API и позволяет выдавать доступ пользователям прямо из Telegram.

## Возможности

- Создание пользователей WireGuard: генерация ключей, конфига и QR-кода
- Список пользователей (пиров) с их IP
- Включение/выключение доступа по пользователю
- Удаление пользователей
- Статистика подключений: трафик (rx/tx) и endpoint каждого пира
- Статус сервера и интерфейса WireGuard
- Удобное меню с кнопками
- Ограничение доступа к боту по Telegram ID и/или паролю

## Требования

- Windows 10/11 или Linux
- Python 3.10+
- MikroTik RouterOS 7.x с включённым API-сервисом (`/ip service set api address=...`)

## Установка

```bash
git clone https://github.com/<your-user>/wireguard-telegram-bot.git
cd wireguard-telegram-bot
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. Создайте бота у [@BotFather](https://t.me/BotFather) и вставьте токен.

### Параметры `.env`

| Параметр            | Описание                                                              |
|---------------------|-----------------------------------------------------------------------|
| `BOT_TOKEN`         | Токен бота от @BotFather                                               |
| `ALLOWED_USERS`     | Telegram ID, которым разрешён доступ (через запятую). Пусто = всем     |
| `BOT_PASSWORD`      | Пароль для входа (`/login`). Пусто = не требуется                      |
| `MT_HOST`           | IP-адрес роутера                                                       |
| `MT_USER`           | Пользователь RouterOS                                                  |
| `MT_PASS`           | Пароль RouterOS                                                        |
| `MT_PORT`           | Порт API: 8728 (без TLS) или 8729 (TLS)                                |
| `MT_USE_TLS`        | `true`/`false` — использовать TLS                                      |
| `WG_INTERFACE`      | Имя WireGuard-интерфейса на роутере (например `wg0`)                   |
| `WG_SUBNET`         | Подсеть клиентских IP (сервер обычно `.1`)                             |
| `WG_SERVER_ADDRESS` | IP сервера в туннеле                                                   |
| `WG_ENDPOINT`       | Публичный адрес и порт сервера, например `1.2.3.4:51820`               |
| `WG_DNS`            | DNS для клиентских конфигов                                            |

### Обход блокировки Telegram API (необязательно)

Если провайдер блокирует `api.telegram.org`, в `main.py` можно указать
рабочий IP-адрес Telegram через `TELEGRAM_API_IP`.

## Запуск

```bash
python main.py
```

### Автозапуск на Windows

- `start_bot.bat` — запуск бота
- `install_autostart.bat` — регистрация автозапуска в реестре (HKCU Run)

## Команды бота

| Команда           | Действие                                     |
|-------------------|----------------------------------------------|
| `/start`          | Главное меню                                  |
| `/help`           | Справка                                       |
| `/login`          | Вход по паролю (если задан `BOT_PASSWORD`)    |
| `/create <имя>`   | Создать пользователя (конфиг + QR-код)        |
| `/peers`          | Список пользователей                         |
| `/toggle <имя>`   | Включить/выключить доступ пользователю       |
| `/delete <имя>`   | Удалить пользователя                          |
| `/status`         | Статус сервера и интерфейса                  |
| `/stats`          | Статистика подключений (трафик)              |

## Безопасность

- Файл `.env` содержит секреты (токен, пароль роутера) — он в `.gitignore`, не загружайте его в публичный репозиторий.
- Используйте сложный `BOT_PASSWORD` и надёжный пароль RouterOS.
- На роутере ограничьте управление только доверенными подсетями и включите API только для них.
